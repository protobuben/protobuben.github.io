Hard problems, solved end to end

Most Roblox work is assembly. These are the ones that were not.

1:1 billiards physics

Full real-world billiards replication: cue impact, spin transfer, cushion response, ball-to-ball collision resolution. Hand-derived from the physics rather than tuned by feel, and implemented in parallel Luau back when the parallel scheduler had close to no documentation and no AI to ask.

Parallel Luau | rigid body dynamics | commercial, client-owned

Machine learning for game AI

Neural-network bots trained with Natural Evolution Strategies to fill low-population servers in a 20-player third-person shooter. Built the whole stack: the tensor and network layer, the trainer, a Studio plugin for running and saving training sessions, and a split-brain bot architecture where aim and movement are separate networks trained in sequence, aim frozen while movement learns on top.

NES optimization | custom tensor library | Studio plugin tooling

Procedural geometry as content

A Conway polyhedron engine: the five Platonic solids as seeds, plus truncate, stellate, and dual as composable operators, so a recipe string like tkD deterministically becomes a mesh. Collectibles are generated, not modeled, which means the content ceiling is combinatorial instead of being capped by how many assets somebody can afford to commission.

Computational geometry | Newell normals | zero external meshes

Gravity-agnostic maze generation

A 3D pipe maze carved by depth-first search over a node graph, then realized in world space by a placer that solves each junction's rotation so tunnels actually meet. There is no global up: the player walks the inside of the structure in any orientation, so the generator cannot lean on a floor plane anywhere.

Graph search | rotation solving | procedural level design

Custom pathfinding with movement prediction

Navigation that leads a moving target instead of chasing where it used to be, built when the stock pathfinding service could not express the behaviour.

Trajectory prediction | navigation

Buffer-packed networking

A typed networking layer with generic send and listen signatures and real connection handles, sitting over a buffer-packing transport so hot channels move bytes instead of tables. Call sites never see the packing layer, which keeps the bandwidth win from leaking into every feature that uses it.

Strict-typed Luau | binary serialization | API design

How I build

Server-authoritative by default

The client asks, the server decides. Validation is part of the design, not a pass added after an exploit shows up.

Strict-typed Luau

Every module fully typed. Type errors are cheaper than bug reports, and a typed boundary is documentation that cannot drift.

Registry-driven content

Adding an item, a rarity tier, or a weapon is one table entry. The thing a client will ask for a hundred times should cost nothing each time.

Flat over nested

Guard clauses and early returns instead of pyramids. Code that stays readable is code somebody can still extend in six months.

Bounded scope, milestone pay

Written scope, split payment, working checkpoints you can see along the way instead of a black box that opens at the end.

Reuse before reinvent

A maintained library of battle-tested modules across projects, so the common half of a job is assembly and the budget goes to the half that is actually new.
