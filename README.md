# Portfolio

Personal portfolio site for Oleksandr Rubtsov (protobuben), Roblox backend and
fullstack engineer.

Static site, no build step and no dependencies. Three files:

| File | What it is |
|---|---|
| `index.html` | All page content |
| `style.css` | Styling and layout |
| `script.js` | Wireframe icosahedron background, plain canvas 2D |

## Local preview

Open `index.html` in a browser. There is nothing to install.

## Deploy

Served by GitHub Pages from the default branch, repo root.
Settings -> Pages -> Source: "Deploy from a branch" -> `main` / `/ (root)`.

## Editing

Content lives directly in `index.html`, one `<section>` per block. Colors and
spacing are CSS custom properties at the top of `style.css`.
